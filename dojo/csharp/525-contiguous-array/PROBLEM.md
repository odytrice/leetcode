# Drill 525: Contiguous Array

LeetCode Medium: https://leetcode.com/problems/contiguous-array/

Return the longest contiguous subarray length containing equal counts of zeros and ones. Return 0 if none exists.

Constraints: 1 to 100,000 binary values.

Example: `[0,1,0]` returns `2`. Implement `FindMaxLength(int[] nums)`.
