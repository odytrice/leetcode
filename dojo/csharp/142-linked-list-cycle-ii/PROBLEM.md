# Drill 142: Linked List Cycle II

LeetCode Medium: https://leetcode.com/problems/linked-list-cycle-ii/

Return the original node where a linked-list cycle begins, or null if there is no cycle. Do not modify the list. Aim for constant extra space. The cycle position used in examples is not a method argument.

Constraints: 0 to 10,000 nodes. `ListNode` is supplied.

Example: `[3,2,0,-4]` with tail pointing to index 1 returns that node. Implement `DetectCycle(ListNode? head)`.
