# Drill 075: Sort Colors

LeetCode Medium: https://leetcode.com/problems/sort-colors/

Sort an array containing only 0, 1, and 2 in place. Do not use a library sorting function. Aim for one pass and constant extra space.

Constraints: 1 to 300 elements.

Example: `[2,0,2,1,1,0]` becomes `[0,0,1,1,2,2]`. Implement `void SortColors(int[] nums)`.
