# Drill 017: Letter Combinations of a Phone Number

LeetCode Medium: https://leetcode.com/problems/letter-combinations-of-a-phone-number/

Return all strings formed by choosing one letter per digit using phone mappings: 2=abc, 3=def, 4=ghi, 5=jkl, 6=mno, 7=pqrs, 8=tuv, 9=wxyz. Any output order is accepted. Empty input returns an empty list.

Constraints: 0 to 4 digits, each 2 through 9.

Example: `"23"` returns `["ad","ae","af","bd","be","bf","cd","ce","cf"]`. Implement `LetterCombinations(string digits)` returning `IList<string>`.
