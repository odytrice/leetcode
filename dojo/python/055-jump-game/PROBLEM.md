# Drill 055: Jump Game

LeetCode Medium: https://leetcode.com/problems/jump-game/

Start at index 0. nums[i] is the maximum forward jump length from i; you may choose any shorter jump. Return whether you can reach the final index.

Constraints: 1 to 10,000 elements in [0,100,000].

Example: `[2,3,1,1,4]` returns true; `[3,2,1,0,4]` returns false. Implement `CanJump(int[] nums)`.
