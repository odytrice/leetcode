# Drill 1143: Longest Common Subsequence

LeetCode Medium: https://leetcode.com/problems/longest-common-subsequence/

Return the length of the longest sequence obtained by deleting zero or more characters from each input without changing the order of remaining characters. A subsequence need not be contiguous.

Constraints: each string has 1 to 1000 lowercase letters.

Example: `"abcde", "ace"` returns `3`. Implement `LongestCommonSubsequence(string text1, string text2)`.
