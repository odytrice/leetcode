# Drill 238: Product of Array Except Self

LeetCode Medium: https://leetcode.com/problems/product-of-array-except-self/

Return an array whose ith entry is the product of all input elements except nums[i]. Use O(n) time without division; aim for constant extra space excluding output.

Constraints: 2 to 100,000 elements in [-30,30]. Prefix, suffix, and answer products fit a signed 32-bit integer.

Example: `[1,2,3,4]` returns `[24,12,8,6]`. Implement `ProductExceptSelf(int[] nums)`.
