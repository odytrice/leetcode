# Drill 001: Two Sum

LeetCode Easy: https://leetcode.com/problems/two-sum/

Given `nums` and `target`, return the two distinct indices whose values sum to target. Exactly one answer exists. Either index order is accepted. Do not reuse an element.

Constraints: 2 to 10,000 integers; values and target between -1e9 and 1e9.

Example: `[2,7,11,15], 9` returns `[0,1]`. Implement `TwoSum(int[] nums, int target)`.
