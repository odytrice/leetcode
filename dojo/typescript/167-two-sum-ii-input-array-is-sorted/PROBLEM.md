# Drill 167: Two Sum II: Input Array Is Sorted

LeetCode Medium: https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/

Given a nondecreasing array with exactly one answer, return the **one-based** indices of two different elements summing to target. Use constant extra space.

Constraints: 2 to 30,000 elements, values and target between -1000 and 1000.

Example: `[2,7,11,15], 9` returns `[1,2]`. Implement `TwoSum(int[] numbers, int target)`.

## Your task

Implement the stubs in `solution.ts` using TypeScript without external libraries. Keep the given names and signatures, and leave the reference solution alone.

Before coding, explain your understanding and proposed approach in chat. The supplied tests are a starting point, not a complete assessment; add cases you think matter.
