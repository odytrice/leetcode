# Drill 567: Permutation in String

LeetCode Medium: https://leetcode.com/problems/permutation-in-string/

Return whether s2 contains a contiguous substring that is a permutation of s1, including repeated-letter counts.

Constraints: each string has 1 to 10,000 lowercase letters.

Example: `"ab", "eidbaooo"` returns `true`. Implement `CheckInclusion(string s1, string s2)`.

## Your task

Implement the stubs in `solution.ts` using TypeScript without external libraries. Keep the given names and signatures, and leave the reference solution alone.

Before coding, explain your understanding and proposed approach in chat. The supplied tests are a starting point, not a complete assessment; add cases you think matter.

Run tests from this folder:

```powershell
node test_solution.ts
```

```powershell

```
