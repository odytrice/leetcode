# Drill 695: Max Area of Island

LeetCode Medium: https://leetcode.com/problems/max-area-of-island/

Return the largest number of land cells in any island of a binary grid. Connections are horizontal and vertical only. Return 0 for no land. You may modify the grid.

Constraints: 1 to 50 rows and columns.

Example: `[[1,1,0],[0,1,0],[1,0,1]]` returns `3`. Implement `MaxAreaOfIsland(int[][] grid)`.

## Your task

Implement the stubs in `solution.ts` using TypeScript without external libraries. Keep the given names and signatures, and leave the reference solution alone.
