# Drill 139: Word Break

LeetCode Medium: https://leetcode.com/problems/word-break/

Return whether s can be segmented into one or more dictionary words. Words can be reused. Every input word is nonempty and dictionary entries are unique.

Constraints: s length 1 to 300; 1 to 1000 dictionary words of length 1 to 20; lowercase letters.

Example: `"leetcode", ["leet","code"]` returns true. Implement `WordBreak(string s, IList<string> wordDict)`.

## Your task

Implement the stubs in `solution.ts` using TypeScript without external libraries. Keep the given names and signatures, and leave the reference solution alone.

Before coding, explain your understanding and proposed approach in chat. The supplied tests are a starting point, not a complete assessment; add cases you think matter.
