# Drill 128: Longest Consecutive Sequence

LeetCode Medium: https://leetcode.com/problems/longest-consecutive-sequence/

Return the length of the longest run of consecutive integer values in an unsorted array. Duplicates do not extend a run. Required time: O(n).

Constraints: 0 to 100,000 integers between -1e9 and 1e9.

Example: `[100,4,200,1,3,2]` returns `4`. Implement `LongestConsecutive(int[] nums)`.

## Your task
