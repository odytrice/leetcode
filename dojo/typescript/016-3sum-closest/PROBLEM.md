# Drill 016: 3Sum Closest

LeetCode Medium: https://leetcode.com/problems/3sum-closest/

Return the sum of three elements at distinct indices closest to `target`. Exactly one closest sum exists. You may sort the input.

Constraints: 3 to 500 integers between -1000 and 1000; target between -10,000 and 10,000.

Example: `[-1,2,1,-4], 1` returns `2`. Implement `ThreeSumClosest(int[] nums, int target)`.

## Your task

Implement the stubs in `solution.ts` using TypeScript without external libraries. Keep the given names and signatures, and leave the reference solution alone.
