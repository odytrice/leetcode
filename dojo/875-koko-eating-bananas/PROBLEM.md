# Drill 875: Koko Eating Bananas

LeetCode Medium: https://leetcode.com/problems/koko-eating-bananas/

At speed k, Koko eats up to k bananas from one pile per hour; leftover time in that hour cannot be used for another pile. Return the minimum positive integer speed to finish within h hours.

Constraints: 1 to 10,000 positive piles, each at most 1e9; piles.Length <= h <= 1e9.

Example: `[3,6,7,11], 8` returns `4`. Implement `MinEatingSpeed(int[] piles, int h)`.
