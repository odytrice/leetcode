# Drill 198: House Robber

LeetCode Medium: https://leetcode.com/problems/house-robber/

Choose nonadjacent houses to maximize the sum of money robbed. Return that maximum. Houses form a line, not a circle.

Constraints: 1 to 100 nonnegative values, each at most 400.

Example: `[2,7,9,3,1]` returns `12`. Implement `Rob(int[] nums)`.

## Your task

Implement the stubs in `Solution.fs` using F# without external libraries. Keep the given names and signatures, and leave the reference solution alone.

Before coding, explain your understanding and proposed approach in chat. The supplied tests are a starting point, not a complete assessment; add cases you think matter.

Run tests from this folder:

```powershell
dotnet fsi test.fsx
```

Or from the `dojo` root:

```powershell
dotnet fsi fsharp/198-house-robber/test.fsx
```

To test the completed reference instead of your solution, add `--reference`.
