# Drill 543: Diameter of Binary Tree

LeetCode Easy: https://leetcode.com/problems/diameter-of-binary-tree/

Return the greatest number of **edges** on any path between two nodes. The path need not pass through the root.

Constraints: 1 to 10,000 nodes. `TreeNode` is supplied.

Example: `[1,2,3,4,5]` returns `3`. Implement `DiameterOfBinaryTree(TreeNode? root)`.

## Your task
