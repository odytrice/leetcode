# Drill 567: Permutation in String

LeetCode Medium: https://leetcode.com/problems/permutation-in-string/

Return whether s2 contains a contiguous substring that is a permutation of s1, including repeated-letter counts.

Constraints: each string has 1 to 10,000 lowercase letters.

Example: `"ab", "eidbaooo"` returns `true`. Implement `CheckInclusion(string s1, string s2)`.
