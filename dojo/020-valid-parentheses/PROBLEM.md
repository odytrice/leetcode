# Drill 020: Valid Parentheses

LeetCode Easy: https://leetcode.com/problems/valid-parentheses/

A string contains only `()[]{}`. Return whether every opening bracket is closed by a matching bracket in the correct nesting order.

Constraints: 1 to 10,000 characters.

Example: `"([])"` is valid; `"([)]"` is not. Implement `IsValid(string s)`.
