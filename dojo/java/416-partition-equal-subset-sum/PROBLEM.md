# Drill 416: Partition Equal Subset Sum

LeetCode Medium: https://leetcode.com/problems/partition-equal-subset-sum/

Return whether the array can be split into two subsets with equal sums. Use each element exactly once across the two subsets. Subsets need not be contiguous.

Constraints: 1 to 200 positive integers in [1,100].

Example: `[1,5,11,5]` returns true. Implement `CanPartition(int[] nums)`.
