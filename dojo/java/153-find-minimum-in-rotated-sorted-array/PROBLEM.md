# Drill 153: Find Minimum in Rotated Sorted Array

LeetCode Medium: https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/

Return the minimum value in a rotated strictly increasing array in O(log n) time.

Constraints: 1 to 5000 unique integers in [-5000,5000]. Rotation may leave the array unchanged.

Example: `[3,4,5,1,2]` returns `1`. Implement `FindMin(int[] nums)`.
