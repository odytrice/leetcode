# Drill 036: Valid Sudoku

LeetCode Medium: https://leetcode.com/problems/valid-sudoku/

Determine whether filled cells in a 9 by 9 board obey Sudoku rules: no repeated digit in any row, column, or 3 by 3 box. `'.'` is empty. A valid partial board need not be solvable.

Example: an empty board is valid; a row containing two `'5'` cells is invalid.

## Your task
