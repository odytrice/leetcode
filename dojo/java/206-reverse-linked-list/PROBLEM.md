# Drill 206: Reverse Linked List

LeetCode Easy: https://leetcode.com/problems/reverse-linked-list/

Reverse a singly linked list by changing next pointers and return its new head. Preserve the original nodes.

Constraints: 0 to 5000 nodes, values in [-5000,5000]. `ListNode` is supplied in `shared/Models.cs`.

Example: `[1,2,3]` returns `[3,2,1]`. Implement `ReverseList(ListNode? head)`.

## Your task

Implement the stubs in `Solution.java` using Java without external libraries. Keep the given names and signatures, and leave the reference solution alone.

Before coding, explain your understanding and proposed approach in chat. The supplied tests are a starting point, not a complete assessment; add cases you think matter.

Run tests from this folder:

```powershell
javac -d build -sourcepath "..;." Main.java
java -cp build Main
```

Or from the `dojo` root:

```powershell

```
