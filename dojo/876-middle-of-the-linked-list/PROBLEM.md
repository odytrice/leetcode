# Drill 876: Middle of the Linked List

LeetCode Easy: https://leetcode.com/problems/middle-of-the-linked-list/

Return the middle node of a nonempty singly linked list. For an even number of nodes, return the second middle. Return the original node, not a copy.

Constraints: 1 to 100 nodes. `ListNode` is supplied in `shared/Models.cs`.

Example: `[1,2,3,4]` returns the node with value 3. Implement `MiddleNode(ListNode head)`.
