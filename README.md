# LeetCode medium patterns

A one-page cheat sheet for the patterns behind most LeetCode medium problems, in TypeScript, Python, Java, C#, F#, C++, Go and Rust. Each pattern has the signals that point to it, a diagram that steps through the idea, and solutions you can paste into LeetCode. Most problems also carry a small play button that opens the NeetCode video walkthrough in a new tab.

Read it at https://odytrice.github.io/leetcode/

## Dojo

[`dojo/`](dojo/) holds practice drills for all 100 problems linked in the cheat sheet, one LeetCode problem per folder, in five languages: C#, Python, TypeScript, Java, and F#. Each drill has a problem statement, a stub to fill in, a separate completed reference, and a test runner. Browse the [catalog by pattern](dojo/CATALOG.md) or see the [dojo README](dojo/README.md) for the practice loop and commands. You need the .NET 10 SDK, Python 3.10+, Node 24, and JDK 21 for the languages you practice.
