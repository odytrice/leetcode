# LeetCode medium patterns

A one-page cheat sheet for the patterns behind most LeetCode medium problems, in TypeScript, Python, Java, C#, F#, C++, Go and Rust. Each pattern has the signals that point to it, a diagram that steps through the idea, and solutions you can paste into LeetCode.

Read it at https://odytrice.github.io/leetcode/

## Dojo

[`dojo/`](dojo/) holds C# practice drills for all 100 problems linked in the cheat sheet, one LeetCode problem per folder. Each has a problem statement, a `Solution.cs` to fill in, a separate completed reference, and a test runner. Browse the [catalog by pattern](dojo/CATALOG.md) or see the [dojo README](dojo/README.md) for the practice loop and commands. You need the .NET 10 SDK.
