# LeetCode medium patterns

A one-page C# cheat sheet for the patterns behind most LeetCode medium problems. Each pattern has the signals that point to it, a diagram that steps through the idea, and C# solutions you can paste into LeetCode.

Read it at https://odytrice.github.io/leetcode/

## Dojo

[`dojo/`](dojo/) holds C# practice drills, one LeetCode problem per folder. Each has a problem statement, a `Solution.cs` to fill in, and a small test runner. See the [dojo README](dojo/README.md) for the practice loop. You need the .NET 10 SDK.
